# sandbox

Standalone Rust workspace for the provider-neutral sandbox contract and its
first concrete provider adapter for E2B. The crates are being extracted from the
Juno (`futex-ai/firna`) monorepo so that other services can depend on them
without depending on Juno.

## Status

The workspace is being bootstrapped. See
[plans/copy-sandbox-crates-from-juno.md](plans/copy-sandbox-crates-from-juno.md)
for the migration plan and
[plans/README.md](plans/README.md) for the plan index.
